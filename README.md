# Student Notesphere

Student Notesphere is a web-based platform designed to help students access and manage academic learning resources such as notes, Previous Year Questions (PYQs), and quizzes.

## Features

- Student Registration and Login
- Student Profile Management
- Teacher Registration and Approval
- Teacher Dashboard
- Upload and Download Notes
- Previous Year Questions (PYQs)
- Online Quizzes
- Admin Dashboard
- User Management
- Teacher Management
- Notes, PYQ and Quiz Management
- JWT-based Authentication
- Google Login
- Email-based Services
- MongoDB Database

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
